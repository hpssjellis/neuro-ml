Free Energy (prediction error) over training ticks

Note on real hardware: the CL1 does not use backprop. Learning in the physical device (and in DishBrain before it) follows a free-energy / predictive-coding loop - predictable sensory feedback acts as reward, unpredictable feedback acts as punishment, and synaptic change follows local Hebbian-style rules rather than global gradient descent. This simulation mirrors that mechanism (reward-modulated Hebbian plasticity gated by a prediction-error / "surprise" signal) rather than faking a backprop-trained network. Comments in the code below map each simulated action to the real CL API (ChannelSet / StimDesign / BurstDesign / Neurons.loop) for later porting to docs.corticallabs.com / cl-sdk.
