Topology


Randomly assigns roles: N zones stim, N sensor, N encourage/discourage (N = floor(total zones / 3)), then randomizes the truth table and influence weights. On the 2×2 grid (too small for a third role group) it splits evenly into 2 stim / 2 sensor with no encourage/discourage zones. Clear Roles resets everything to Unused. Undo restores the state from just before the last Randomize / Clear.

How this training actually works

Each trial, the current stim pattern is multiplied through a simple weight matrix (one weight per stim→sensor pair) to get an "actual" sensor output. In Training mode, any gap between that output and the truth table's desired output nudges the relevant weights up or down (a basic error-correction / Hebbian-style rule) — the size of the nudge scales with the average frequency set on the Encourage zones, while Discourage zones bias weight changes downward. In Inference mode, weights are just read out, not changed. This is a rough software analogy for how repeated, targeted electrical stimulation might reinforce or weaken pathways in a living neural culture on a real HD-MEA chip — it does not model real neuron biophysics, plasticity mechanisms, or noise.
⚠️ This is a simulation only. It is a teaching sandbox for exploring the idea of closed-loop stimulation and training on an HD-MEA array. Whether anything like this training rule actually works on real biological neurons is an open research question that would require significant wet-lab validation. Use at your own risk — do not treat this tool's output as a validated protocol for real hardware or living tissue.
